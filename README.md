📝 Todo List Backend

A simple Todo List REST API built with Node.js as a learning project.

I created this project to understand the fundamentals of backend development and how CRUD operations work in a REST API.

🎯 Purpose

This project was created purely for learning and practice.

Through this project, I practiced how to:

Create a backend server using Node.js
Create REST API endpoints
Handle HTTP requests and responses
Implement CRUD operations
Work with API routes
Test backend APIs
🛠️ Tech Stack
Node.js
Express.js
JavaScript
REST API
🚀 CRUD Operations

The API supports the basic operations required to manage todos:

Operation	HTTP Method	Purpose
Create	POST	Create a new todo
Read	GET	Get todos
Update	PUT	Update a todo
Delete	DELETE	Delete a todo
.

🧪 Testing

The API can be tested using tools such as:

Postman

cURL
